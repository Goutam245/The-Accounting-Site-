# The Accounting Site

Ontario's trusted bookkeeping, sales tax, payroll, and corporate tax compliance specialists.

## Overview

The Accounting Site provides high-volume compliance services for Ontario businesses — covering bookkeeping, HST/GST filing, payroll, and corporate tax. Built for small and medium businesses that need accuracy, speed, and reliability month after month.

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Framer Motion
- React Router v6
- Deployed on Netlify

## Pages

- **Home** — Hero, Trust Bar, What We Do, Process, Pricing CTA, Testimonials
- **Services** — Bookkeeping, HST/GST Filing, Payroll, Corporate Tax, Financial Reporting
- **Pricing** — Tiered packages (Essentials, Growth, Premium)
- **Software** — QuickBooks Online, Xero, Hubdoc, Dext, Wagepoint, Rotessa
- **Resources** — Blog, Guides, Time Value Calculator
- **About** — Story, Mission, Why Us Comparison
- **Contact** — Contact Form + Booking

## Features

- Interactive pricing packages with email gate
- Time Value Calculator on Resources page
- Dynamic compliance dashboard with live dates
- Fully responsive (mobile-first)
- SEO optimized

## Development

Built from scratch based on client brand guidelines and site architecture documentation. Design follows warm, clean aesthetic tailored for Ontario-based service businesses.
